Interpret the evidence

Implemented means the code exists at a named revision. Local qualification records a passing local gate. Independent coding-agent review is a second implementation review. Milestone closure refers to an explicitly accepted scope. Publication status in the commit catalogue records reachability from the edition’s recorded public heads at this cutoff.

The older atlas is presented with its October cutoff. It contains then-open work that later chapters resolve. Current local arm64 receipts establish their named cases and source revisions. Required native Linux, intact newer-language admission and full-corpus compatibility remain open where identified.

Editorial grouping

Earliest named phase head containing the commit, in listed order. Original-oracle-only commits have their own phase. Topics use subject matching. Dates shown by default are author dates.

Git dates can differ after rebasing or a signed history rewrite. The catalogue retains both author and committer dates. A phase is an explanatory grouping, not a release declaration.

Preserved corrections

  • The original oracle is another Ledger 8 line, with an earlier shared ancestor than the selected AST base.
  • The 0.3.0 closeout retains composite evidence and the failed full run.
  • Forge's local reuse measurements do not quantify whole-CI savings.
  • A pragma-only derivative has a different source identity from the original fixture.

Maintain the book

Markdown chapters, frozen records, static assets and a small Python builder live in site/compact-journey. The site is pre-rendered and published through the existing Pages branch. Updating it requires no compiler, key generation or additional CI workflow.
