Where the story stands

Ledger 9 foundation merged. PR #725 brought the SDK and toolchain migration into the working branch.

Upstream compatibility continues locally. Recent cryptography, event, serialization and proof results have named arm64 source revisions. Full corpus, native Linux qualification and generated two-contract execution remain open.
