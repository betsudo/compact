The shared semantic thread

Compact source flows through shared frontend analysis into a typed internal model. Checked lowering assigns legal target operations. The Rust AST renderer constructs syntax, while the runtime delegates protocol behavior to the ledger SDK.

Native execution and recorded execution expose different results from the same admitted behavior. Proof preparation binds the observed operation, verifier and statement. Proving and ledger application add their own acceptance gates.

What type safety contributes

A separate Rust carrier can prevent an ordinary K1 call from accepting a P-256 value. Checked decoding can refuse malformed bytes at a host boundary. Neither replaces validation of the installed operation or cryptographic verification of a statement.
